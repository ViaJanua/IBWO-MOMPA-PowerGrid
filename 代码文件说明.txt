
一、前端 Vue 组件（src/components/）
1. HeaderNav.vue
   顶部导航栏组件。
   - 显示平台 Logo 和名称
   - 导航菜单：首页 / 技术栈 / 电网模拟器 / 算法介绍 / 三维展示 / 关于平台
   - 右侧显示系统运行状态
   - 根据登录状态显示用户头像/昵称或“登录/注册”链接

2. FooterBar.vue
   底部页脚组件。
   - 版权信息
   - 隐私政策、联系我们链接

3. EChartsPanel.vue
   通用 ECharts 图表封装组件。
   - 接收 title 和 option 属性
   - 自动初始化图表、监听数据变化重新渲染
   - 使用 ResizeObserver 实现自适应大小
   - 组件销毁时释放图表实例

4. MetricCards.vue
   概览指标卡片组件。
   - 展示日总购电成本、网损降低率、电压合格率、峰谷差削减率
   - 数据来自父组件传入的 summary 对象
   - 自动格式化数值（保留两位小数）

5. RegulationTable.vue
   逐时调节方案表格组件。
   - 显示各时段（24小时）的详细调度数据：
     储能功率、SOC、OLTC档位、SVC出力、电容器投切（17/29/32号）、需求响应比
   - 储能功率正负值分别用绿色/红色区分充放电
   - 空数据时显示“暂无数据”

6. SceneSelector.vue
   场景选择器组件。
   - 下拉选择季节（春/夏/秋/冬）
   - 下拉选择新能源渗透率（0%/5%/10%/15%）
   - 点击“更新数据”按钮触发父组件的 update 事件
   - 显示加载状态和当前场景名称

7. ThreeScene.vue
   Three.js 3D 场景封装组件。
   - 加载 GLTF 电网模型（grid_model.glb）
   - 支持 OrbitControls 交互（左键平移、右键旋转、滚轮缩放）
   - 若模型加载失败则自动创建备用立方体场景
   - 提供 toggleAutoRotate、resetCamera、getAutoRotate 方法供父组件调用


二、前端页面视图（src/views/）
1. HomeView.vue
   首页页面。
   - 首屏 Hero：平台标题、简介、关键数据（16场景、94.28%降损等）
   - 核心功能模块展示（双算法协同、多场景仿真、可视化、调节方案）
   - 技术栈简介区域

2. DataView.vue
   电网模拟器主页面（核心交互页）。
   - 集成 SceneSelector 进行场景切换
   - 模式选项：极速（读取预计算 CSV）、精确（调用实时算法）
   - 展示 MetricCards 指标卡片
   - 展示 4 个 ECharts 图表：功率平衡、网损对比、节点最低电压、储能充放电与SOC
   - 展示逐时调节方案（文字描述 + RegulationTable 表格）
   - 调度计划概要统计（总充电/放电量、购电费用、碳减排、平均SOC）

3. AlgorithmView.vue
   算法介绍页面。
   - 详细介绍 IBWO 和 MOMPA 算法的改进点（各4项）
   - 展示决策变量维度
   - 闭环迭代流程图
   - 16组场景的电压合格率和网损降低率结果表格
   - 高亮最佳结果（春季15%渗透率）

4. TechStackView.vue
   技术栈展示页面。
   - 列出 Vue 3、ECharts、TypeScript、Flask、PostgreSQL、WebSocket、Three.js、Python算法服务
   - 每个技术有简要描述和标签
   - 底部展示微服务架构说明

5. LoginView.vue
   登录/注册页面。
   - 标签切换：登录 / 注册
   - 登录表单：账号 + 密码
   - 注册表单：账号、昵称、密码、确认密码（头像上传选项已预留）
   - 登录成功后跳转首页，并保存用户信息到 localStorage
   - 已登录时显示个人中心（昵称、固定头像、退出按钮）

6. ThreeView.vue
   三维展示页面。
   - 嵌入 ThreeScene 组件（占满场景区域）
   - 提供自动旋转切换和重置视角按钮
   - 下方显示图例说明（节点电压、线路潮流、设备状态）


三、前端工具与配置（src/api、composables、router 等）
1. api/auth.js
   认证 API 封装。
   - loginAPI(account, password)  POST /api/auth/login
   - registerAPI(formData)        POST /api/auth/register（表单提交，含头像）

2. api/request.js
   统一请求封装。
   - 自动附加 JWT Token（从 localStorage 读取）
   - 自动处理 401 响应（清除 token 并跳转登录）
   - 支持 JSON 和 FormData 两种请求体
   - 返回解析后的 JSON 数据

3. composables/useAuth.js
   用户状态管理组合式函数。
   - 维护 user、token 响应式变量
   - 自动同步到 localStorage（watch 监听）
   - 提供 isLoggedIn 计算属性、storeUser()、logout() 方法
   - 应用启动时自动恢复登录状态

4. router/index.js
   Vue Router 路由配置文件。
   - 路由表：/ (HomeView), /tech-stack, /data, /algorithm, /login, /three
   - 404 重定向到首页
   - 使用 createWebHistory 模式

5. main.js
   Vue 应用入口。
   - 创建 app 实例
   - 注册路由
   - 导入全局样式 style.css
   - 挂载到 #app

6. App.vue
   根组件，仅包含 <router-view />。

7. index.html
   主 HTML 模板，包含 <div id="app"> 和模块入口 script。

8. package.json / package-lock.json
   前端项目依赖管理（Vue 3, Vite, ECharts, Three.js, vue-router 等）。

9. vite.config.js
   Vite 构建配置。
   - 路径别名 '@' 指向 src 目录
   - 开发代理：/api 和 /uploads 转发到 http://127.0.0.1:5000
   - 开发服务器端口 5173

10. assets/style.css
    全局样式。
    - CSS 变量（颜色、字体等）
    - 容器、卡片、按钮等通用样式
    - 响应式工具


四、后端 Python 服务（项目根目录）
1. app.py
   Flask 主应用。
   - 初始化 Flask、CORS、JWT 管理器
   - 注册 API 路由：
     * /api/auth/register  用户注册（支持头像上传）
     * /api/auth/login     登录（返回 JWT token）
     * /api/auth/me        获取当前用户信息（需 JWT）
     * /api/data           获取指定场景的调度数据（读取 CSV）
     * /api/all-scenes     获取所有场景汇总指标
     * /api/run_algorithm  调用实时算法计算指定场景
     * /uploads/<filename> 头像静态资源访问
   - 数据库操作：SQLite（users.db），存储用户账号、密码哈希、昵称、头像路径
   - 前端静态文件服务（catch-all 路由，返回 index.html）

2. coordinated_dispatch.py
   核心调度算法模块。
   - 实现 IBWO（改进黑寡妇优化算法）经济调度
   - 实现 MOMPA（改进多目标海洋捕食者算法）无功优化
   - 外层闭环迭代：有功-无功协同交替优化
   - 调用 pandapower 进行潮流计算（IEEE 33 节点）
   - 输出逐时调度数据（24小时）和场景汇总指标
   - 自动生成调度结果图和收敛曲线（matplotlib）
   - 支持通过 Settings 类配置种群大小、迭代次数、季节、渗透率等
   - 提供 run() 函数供 app.py 调用

3. data_loader.py
   数据加载器。
   - 从 data/ 目录的 Excel 文件（electric_zero.xlsx 等）读取四季负荷、风电、光伏数据
   - 读取电价数据（四个典型日数据.xlsx）
   - 使用 pickle 缓存已加载数据，加速重复调用
   - 返回格式：字典 { "load": ndarray, "wt": ndarray, "pv": ndarray, "price": ndarray }

4. IBWO/ieee33_pf.py
   IEEE 33 节点配电网模型。
   - 使用 pandapower 构建 33 节点辐射状网络
   - 定义基准负荷分布（LOAD_RATIO）
   - 提供 build_ieee33_network() 函数，支持设置根节点电压
   - 被 coordinated_dispatch.py 调用于每次潮流计算

5. requirements.txt
   Python 依赖清单（Flask, flask-cors, flask-jwt-extended, pandapower, pandas, numpy, matplotlib, openpyxl 等）。

6. 部署说明.txt
   部署文档（环境要求、安装依赖、启动服务、端口放行、常见问题）。

7. .gitignore
   忽略规则（Python 缓存、虚拟环境、IDE 配置等）。

8. users.db
   SQLite 数据库文件（启动后自动创建），存储用户表。

六、文件依赖关系简述
1. 前端启动流程：
   index.html → main.js → App.vue → 路由加载对应 View
   View 中引用 components、composables、api 等

2. 后端启动流程：
   app.py → 初始化数据库 → 注册路由 → 监听端口
   收到 /api/run_algorithm 请求后调用 coordinated_dispatch.run()
   run() 内部调用 data_loader 加载数据、调用 IBWO/MOMPA 算法、调用 pandapower 潮流计算，最终生成 CSV 和图表

3. 前端调用后端：
   DataView.vue 通过 fetch 调用 /api/data 或 /api/run_algorithm，结果渲染到图表和表格中
   LoginView.vue 调用 /api/auth/login 和 /api/auth/register

4. 用户认证流程：
   登录成功 → 后端返回 token 和 user 信息 → 前端存储到 localStorage → 后续请求自动携带 Bearer token
   退出登录 → 清除 localStorage → 跳转登录页
