智能电网实时模拟平台 - 部署说明

一、环境要求
----------------------------------------
- 操作系统：Windows / Linux / macOS 均可
- Python 版本：3.9 或以上
- 网络：需要联网（安装依赖库）


二、安装 Python 依赖
----------------------------------------
在项目根目录（即 app.py 所在目录）打开终端/CMD，执行：

pip install -r requirements.txt

如果网速慢，使用国内镜像源（清华大学）：
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple


三、启动服务
----------------------------------------
在项目根目录执行：
python app.py

看到以下信息即启动成功：
"Running on http://0.0.0.0:5000"


四、访问平台
----------------------------------------
- 服务器本机访问：http://localhost:5000
- 同网络下其他设备：http://[服务器IP地址]:5000

例如：http://192.168.1.100:5000

注意：如果无法访问，检查服务器防火墙是否开放了 5000 端口。


五、常见问题排查
----------------------------------------
1. 端口被占用：
   修改 app.py 最后一行 port=5000 改为其他端口，如 8080
   然后访问 http://IP:8080

2. 云服务器无法访问：
   需要在云服务商控制台 → 安全组 → 放行对应端口（入方向规则）

3. Windows 防火墙拦截：
   控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则
   选择“端口” → TCP → 特定本地端口 5000 → 允许连接

4. 提示缺少某个库：
   单独安装，例如：pip install pandas

5. 提示 ModuleNotFoundError: No module named 'pandapower'：
   单独安装：pip install pandapower

6. 页面空白或显示“加载失败”：
   检查终端是否有红色报错信息，截图联系开发人员


六、平台使用说明
----------------------------------------
1. 极速模式（默认）：
   - 读取 data/ 文件夹下预计算的 CSV 数据
   - 响应速度：秒开
   - 适用场景：日常演示、快速查看

2. 精确模式：
   - 调用 IBWO-MOMPA 双算法实时计算
   - 响应速度：约 2-3 分钟（取决于服务器性能）
   - 适用场景：追求最优调度方案、展示算法能力


七、文件说明
----------------------------------------
- app.py                   后端服务主程序
- coordinated_dispatch.py  核心算法（IBWO + MOMPA）
- data_loader.py           数据加载器
- IBWO/                    IEEE 33 节点电网模型
- data/                    预计算的 16 组场景数据
- frontend/dist/           前端页面（已打包）
- uploads/                 用户头像存储目录
- users.db                 用户数据库（启动后自动生成）
